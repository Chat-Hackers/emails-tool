# Email Summary

Email Summary tool for Chathackers Matrix chat integration tools.

This tool creates email summaries for a group chat. Users enter a list of emails on the dashboard, select daily, weekly or monthly summaries and then the tool collects them together and sends them out

## Getting started

1. Clone the repo
1. Run the command `npm install`
1. Run the command `npm run dev`
1. Copy the `emails.json` file and paste into the `registrations` folder of [the wrapper project](https://github.com/chat-hackers/tool-hub)
1. Set it to daily email digest for your group
1. Marvel in delight at your newfound power
